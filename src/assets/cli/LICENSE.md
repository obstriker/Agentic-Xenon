# CLI marks

SVGs from `@lobehub/icons-static-svg` v1.101.0 (MIT, https://github.com/lobehub/lobe-icons), monochrome variants.
The marks themselves are trademarks of their owners (Anthropic, OpenAI, Google, Cursor, and so on) and are used
only to identify the tool an agent runs in. `omp.svg` is the glyph from the favicon of https://omp.sh/, flattened to one colour (no gradient or tile). pi has no published logo; the app draws a π for it.
